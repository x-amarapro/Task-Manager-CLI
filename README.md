# Task Manager CLI
[https://github.com/x-amarapro/Task-Manager-CLI/blob/main/task_manager_CLI_practice_project.py](https://roadmap.sh/projects/task-tracker)

## Description

A simple command-line task manager built in Python.
Allows users to add, update, view, and delete tasks with persistent storage using JSON.
Users can run command thrrough Interactive Menu within the terminal.

## Features

* Add tasks
* View all tasks
* Filter tasks by status (complete, in progress, incomplete)
* Update task name and status
* Delete tasks
* Save/load tasks using a JSON file
* Interactive Menu in CLI Terminal

## How to Run

Make sure you're in the project folder, then run:

python task_manager_CLI_practice_project.py <command>

## Commands

view → View all tasks
view_completed → View completed tasks
view_in_progress → View tasks in progress
view_incomplete → View incomplete tasks

add → Add a new task
update_name → Update a task name
update_status → Update task status

remove → Delete a task
clear_completed → Remove all completed tasks

## Example

python task_manager_CLI_practice_project.py add
python task_manager_CLI_practice_project.py view
